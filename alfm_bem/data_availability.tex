\section*{Data and Code Availability Statement}

This submission includes all code and instructions required to reproduce the results reported in the paper.

\subsection*{Code Access}

The complete implementation is included in the submission archive under the \texttt{alfm\_bem/} directory. A public mirror (if needed) is:
\begin{center}
\url{https://github.com/davidahmann/coherism/tree/main/alfm_bem}
\end{center}

\subsection*{Contents}

The code package includes:
\begin{itemize}
    \item \textbf{Source code}: ALFM-BEM wrapper, BEM storage/query, Consensus Engine, bounded adapters, and projection layer
    \begin{itemize}
        \item Bidirectional Experience Memory (BEM) with risk, success, and coverage signals
        \item Consensus Engine with Trust, Abstain, Escalate, and Query actions
        \item Bounded Adapters with gradient clipping, norm projection, and EMA smoothing
        \item Contrastive Projection layer for high-dimensional embedding spaces
    \end{itemize}
    \item \textbf{Experiments}: Scripts to reproduce all experimental results and figures:
    \begin{itemize}
        \item \texttt{phase1\_runner.py}: Multi-seed synthetic experiments used for the main tables/figures
        \item \texttt{generate\_figures.py}: Regenerates paper figures from experiment outputs
        \item \texttt{threshold\_sensitivity.py}: Parameter sensitivity analysis
        \item \texttt{domain\_shift\_experiment.py}: Adapter stability under distribution shift
        \item \texttt{real\_embeddings.py}: Real-world text embeddings experiment using 20Newsgroups and Sentence-Transformers
        \item \texttt{healthcare\_simulator.py}: Healthcare claims processing case study
    \end{itemize}
    \item \textbf{Documentation}: \texttt{README.md}, pinned dependencies (\texttt{requirements.lock}), and build targets (\texttt{Makefile})
\end{itemize}

\subsection*{Reproducibility}

All experiments use fixed random seeds where applicable. Multi-seed results are reported as mean $\pm$ standard deviation. Dependencies are pinned in \texttt{requirements.lock}.

To reproduce the full paper build (figures, tables, PDF) from a clean environment:
\begin{center}
\texttt{cd alfm\_bem \&\& make install \&\& make test \&\& make figures \&\& make paper}
\end{center}

\subsection*{Data Sources}

\textbf{Synthetic experiments} are generated by the included code and require no external data. \textbf{Real-world embeddings} use the public 20Newsgroups dataset (\texttt{sklearn.datasets.fetch\_20newsgroups}) and Sentence-Transformers model \texttt{all-MiniLM-L6-v2}; these are downloaded automatically on first run and cached locally.
